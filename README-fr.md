## 💡 Êtes-vous confronté à ces défis?

> 🤔 Lorsque vous analysez des problèmes, restez-vous toujours en surface?
> 🔍 Voulez-vous réfléchir profondément mais ne savez pas par où commencer?
> 💭 Faites-vous face à des décisions complexes sans méthodologie systématique?

**Deep Thinking Workflow** est conçu pour vous — une méthodologie de réflexion progressive qui rend la pensée profonde exécutable et reproductible.

## 🚀 Démarrage Rapide

### Utilisation Basique

```
Utilisateur: Comment réfléchir profondément?
Assistant: Veuillez décrire le sujet ou la question sur laquelle vous souhaitez réfléchir profondément...
```

### Modes d'Exécution

**1️⃣ Exécution Progressive (Recommandée)**
- Exécuter par phases avec des points de contrôle pour votre intervention
- Ajustez la direction de l'analyse à tout moment, ajoutez des informations
- 📖 [Guide Détaillé](skill.md#exécution-progressive)

**2️⃣ Exécution en Une Étape**
- Terminez toutes les analyses en une fois (Niveaux 1-3 chaîne complète)
- Adapté aux besoins de réflexion simples et rapides

### Chargement par Niveaux

| Niveau | Objectif | Cadre | Temps |
|--------|----------|-------|-------|
| **Niveau 1** | Analyse Rapide | Cadre 5W1H | ~30s |
| **Niveau 2** | Analyse Profonde | Pensée Critique + Systémique | ~2min |
| **Niveau 3** | Perspicacité Essentielle | Validation Croisée Multidimensionnelle + Principes Premiers | ~10min |

## 🧩 Modules de Sous-compétences

### Méta-compétence

#### 🔮 Réflexivité
> Identifie l'influence mutuelle entre le penseur et le système, évite les biais cognitifs

**Cas d'Usage**: Auto-vérification pré-décision, identification des biais, clarification de position
**Priorité**: Activée en premier

---

### Sous-compétences Principales

#### 🔍 Pensée Critique
> Évalue la qualité de l'argument, identifie les sophismes logiques, examine les hypothèses

**Méthodes**:
- Clarification des Valeurs
- Séparation Fait/Opinion
- Principes Premiers + 5 Pourquoi
- Détection de Sophismes Logiques

**Cas d'Usage**: Analyser la fiabilité des points de vue, évaluer la force des arguments

#### 🌐 Pensée Systémique
> Comprend les relations entre éléments, identifie les boucles de rétroaction, prédit le comportement du système

**Méthodes**:
- Matrice d'Attribution Multidimensionnelle
- Analyse de Cascade de 2e/3e Ordre
- Étirement d'Échelle de Pratique

**Cas d'Usage**: Analyse de problèmes complexes, décisions multifactorielles

#### 💡 Pensée Créative
> Dépasse les schémas de pensée, génère des洞察 uniques, connecte les connaissances interdisciplinaires

**Méthode**: SCAMPER

**Cas d'Usage**: Innovation produit, résolution de problèmes, conception de solutions

#### 📝 Expression Structurée
> Transforme les résultats de la réflexion en sortie claire

**Cas d'Usage**: Rédaction, discours, présentations, documentation

---

### Analyse Multi-perspectives

#### 👥 Six Perspectives

| Perspective | Focus Central | Question Clé |
|-------------|---------------|--------------|
| 🧠 Psychologie | Motivation/Cognition/Émotion | Que veut vraiment l'utilisateur? |
| 📡 Communication | Information/Symbole/Influence | Comment l'information est-elle reçue et déformée? |
| 📦 Produit | Besoins/Valeur/Itération | Quoi construire qui ait du sens? |
| 💰 Économie | Incitations/Demande-Offre/Coût | Qu'est-ce qui驱动 le comportement? |
| 🏛️ Politique | Pouvoir/Intérêt/Alliance | Comment les parties jouent-elles? |
| 🎨 Design | Expérience/Empathie/Essence | Qu'est-ce qui émeut l'utilisateur? |

Modifiez `config/config.json` pour personnaliser le comportement:

```json

  "load_config": {

    "max_level": 3,
    "auto_escalation": true

  "output_config": {
    "auto_generate": true,
    "markdown_template": "default",
    "html_template": "assets/thinking_output.html",

      "systemic_thinking": true,
      "first_principles": true,
      "multi_perspective": true,
      "confidence_assessment": true

  }
```

## 🔧 Utilisation des Scripts

### Moteur Python

```bash
# Analyse rapide
python script/deep_think.py --input "Votre question"

# Analyse de pensée critique
python script/deep_think.py --input "Votre argument" --skill critical

# Analyser depuis un fichier
python script/deep_think.py --file argument.txt --output markdown
```

### Moteur JavaScript

```javascript
const { DeepThinkEngine } = require('./script/think_engine.js');

const engine = new DeepThinkEngine();
const result = engine.analyzeArgument("Votre argument...");

console.log(result.markdown);
```

## 📖 Principes de Conception

| Principe | Description |
|----------|-------------|
| **Chargement Progressif** | Charge les sous-compétences à la demande, évite la surcharge cognitive |
| **Piloté par les Métadonnées** | Chaque nœud de réflexion porte confiance, source, etc. |
| **Persistance de Mémoire** | Processus de réflexion enregistré automatiquement, récupération inter-sessions |
| **Sortie Structurée** | Support multi-format JSON/Markdown/HTML |
| **Contrôle Total Utilisateur** | Conception avec points de contrôle assure que l'utilisateur contrôle la direction |
