> 🤔 When analyzing problems, do you always stay on the surface?

| Feature | Description |
|---------|-------------|

## 🚀 Quick Start

### Basic Usage

```
User: How to think deeply?
Assistant: Please describe the topic or question you want to think deeply about...
```

### Execution Modes

**1️⃣ Progressive Execution (Recommended)**
- Execute in phases with checkpoints for your input
- Adjust analysis direction anytime, add more information
- 📖 [Detailed Guide](skill.md#progressive-execution)

**2️⃣ One-Step Execution**
- Complete all analysis at once (Level 1-3 full chain)
- Suitable for simple and quick thinking needs

### Level Loading

| Level | Goal | Framework | Time |
|-------|------|-----------|------|
| **Level 1** | Quick Analysis | 5W1H Framework | ~30s |
| **Level 2** | Deep Analysis | Critical Thinking + Systemic Thinking | ~2min |
| **Level 3** | Essential Insight | Multi-dimension Cross-validation + First Principles | ~10min |

## 🧩 Sub-Skill Modules

### Meta-Skill

#### 🔮 Reflexivity
> Identify the mutual influence between thinker and system, avoid cognitive bias

**Use Cases**: Pre-decision check, bias identification, stance clarification
**Priority**: Activated first

---

### Core Sub-Skills

#### 🔍 Critical Thinking
> Evaluate argument quality, identify logical fallacies, examine assumptions

**Methods**:
- Value Clarification
- Fact/Opinion Separation
- First Principles + 5 Why
- Logical Fallacy Detection

**Use Cases**: Analyzing viewpoint reliability, evaluating argument strength

#### 🌐 Systemic Thinking
> Understand element relationships, identify feedback loops, predict system behavior

**Methods**:
- Multi-dimension Attribution Matrix
- Second/Third-order Cascade Analysis
- Practice Scale Stretching

**Use Cases**: Complex problem analysis, multi-factor decisions

#### 💡 Creative Thinking
> Break through thinking patterns, generate novel insights, connect cross-domain knowledge

**Method**: SCAMPER

**Use Cases**: Product innovation, problem solving, solution design

#### 📝 Structured Expression
> Transform thinking results into clear output

**Use Cases**: Writing, speeches, presentations, documentation

## ⚙️ Configuration

Edit `config/config.json` to customize behavior:

```json
{
  "load_config": {
    "default_level": 1,
    "max_level": 3,
    "auto_escalation": true
  },
  "output_config": {
    "auto_generate": true,
    "markdown_template": "default",
    "html_template": "assets/thinking_output.html",
    "required_sections": {
      "reflexivity": true,
      "critical_thinking": true,
      "systemic_thinking": true,
      "first_principles": true,
      "multi_perspective": true,
      "confidence_assessment": true
    }
  }
}
```

## 🔧 Script Usage

### Python Engine

```bash
# Quick analysis
python script/deep_think.py --input "Your question"

# Critical thinking analysis
python script/deep_think.py --input "Your argument" --skill critical

# Analyze from file
python script/deep_think.py --file argument.txt --output markdown
```

### JavaScript Engine

```javascript
const { DeepThinkEngine } = require('./script/think_engine.js');

const engine = new DeepThinkEngine();
const result = engine.analyzeArgument("Your argument...");

console.log(result.markdown);
```

## 📖 Design Principles

| Principle | Description |
|-----------|-------------|
| **Progressive Loading** | Load sub-skills on demand, avoid cognitive overload |
| **Metadata Driven** | Each thinking node carries confidence, source, etc. |
| **Memory Persistence** | Thinking process auto-saved, cross-session recovery |
| **Structured Output** | JSON/Markdown/HTML multi-format support |
| **Full User Control** | Checkpoint design ensures user controls direction |
