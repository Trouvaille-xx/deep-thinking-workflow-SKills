## 💡 こんなお悩みはありませんか？

> 🤔 問題を分析しても、いつも表面的な話しか浮かばない
> 🔍 深く考えたいけど从何から手をつければいいのかわからない
> 💭 複雑な意思決定迫られていて、体系的な方法論がない
> 📝 思考過程がごちゃごちゃで、結果をまとめるのが難しい

**Deep Thinking Workflow** はそのようなあなたのために存在します — 深い思考を実行可能にし、再現可能な段階的な思考法です。

---

## ✨ コア機能

| 機能 | 説明 |
|------|------|
| 🏗️ **3段階漸進モード** | クイック分析 → 構造的深化 → 本質的洞察 |
| 🔧 **モジュール式サブスキル** | 批判的思考、体系的思考、創造的思考... |
| 🎯 **多角的分析** | 心理学、伝播学(Product)、経済学... |
| 📊 **視覚化出力** | Markdown + HTML + ECharts インタラクティブチャート |
| 🛑 **段階的実行** | キーポイントでチェックポイント、全方位コントロール |

## 🚀 クイックスタート

### 基本的な使い方

```
ユーザー: 深い思考怎么做？
アシスタント: 深く考えたい問題やテーマを教えてください...
```

### 実行モード

**1️⃣ 段階的実行（推奨）**
- フェーズ별로実行し、チェックポイントで介入可能
- 分析方向の調整、情報追加がいつでも可能
- 📖 [詳細ガイド](skill.md#段階的実行)

**2️⃣ 一括実行**
- 一회에全分析を完了（Level 1-3 フルチェーン）
- シンプルで素早い思考ニーズに適合

### レベル別処理

| レベル | 目標 | フレームワーク | 時間 |
|--------|------|---------------|------|
| **Level 1** | クイック分析 | 5W1H フレームワーク | ~30秒 |
| **Level 2** | 深い分析 | 批判的思考 + 体系的思考 | ~2分 |
| **Level 3** | 本質的洞察 | 多面的交差検証 + 第一原理 | ~10分 |

## 🧩 サブスキルモジュール

### メタスキル

#### 🔮 反射性 (Reflexivity)
> 思考者とシステムの相互影響を識別し、認知的バイアスを回避

**適用シーン**: 意思決定前の自己チェック、バイアス識別、立場明確化
**優先度**: 最初にアクティブ化

---

### コアサブスキル

#### 🔍 批判的思考 (Critical Thinking)
> 引数の質を評価し、論理的誤謬を識別し、前提を検証

**メソッド**:
- 価値明確化
- 事実/意見的分離
- 第一原理 + 5Why分析
- 論理的誤謬検出

**適用シーン**: 見解の信頼性分析、引数の強度評価

#### 🌐 体系的思考 (Systemic Thinking)
> 要素の関係を理解し、フィードバックループを識別し、システム行動を予測

**メソッド**:
- 多面的帰属マトリクス
- 2次/3次伝導分析
- 実践スケール伸展

**適用シーン**: 複雑な問題分析、多要素意思決定

#### 💡 創造的思考 (Creative Thinking)
> 思考パターンを突破し、新鮮な洞察を生み出し、分野横断的な知識を結びつける

**メソッド**: SCAMPER

**適用シーン**: プロダクトイノベーション、問題解決、ソリューション設計

#### 📝 構造化表現 (Structured Expression)
> 思考結果を明確な出力に変換

**適用シーン**: ライティング、スピーチ、プレゼンテーション、ドキュメント作成

---

### 多角的分析

#### 👥 6つの視点

| 視点 | コア関心 | 核心質問 |
|------|----------|----------|
| 🧠 心理学 | 動機/認知/感情 | ユーザーは本当に何を望んでいるのか？ |
| 📡 伝播学 | 情報/記号/影響 | 情報はどのように受信・歪曲されるのか？ |
| 📦 プロダクト | ニーズ/価値/反復 | 何を построитьべきなのか？ |
| 💰 経済学 | インセンティブ/供需/コスト | 什么が行動を引き起こすのか？ |
| 🏛️ 政治学 | 権力/利益/同盟 | 各はどう博弈しているのか？ |
| 🎨 デザイン | 体験/共感/本質 | 什么がユーザーを動かすのか？ |

## ⚙️ 設定

`config/config.json` を編集して動作をカスタマイズ：

```json
{
  "load_config": {
    "default_level": 1,
    "max_level": 3,
    "auto_escalation": true
  },
  "output_config": {
    "auto_generate": true,
    "markdown_template": "default",
    "html_template": "assets/thinking_output.html",
    "required_sections": {
      "reflexivity": true,
      "critical_thinking": true,
      "systemic_thinking": true,
      "first_principles": true,
      "multi_perspective": true,
      "confidence_assessment": true
    }
  }
}
```

## 🔧 スクリプト使用

### Python エンジン

```bash
# クイック分析
python script/deep_think.py --input "あなたの質問"

# 批判的思考分析
python script/deep_think.py --input "あなたの引数" --skill critical

# ファイルから分析
python script/deep_think.py --file argument.txt --output markdown
```

### JavaScript エンジン

```javascript
const { DeepThinkEngine } = require('./script/think_engine.js');

const engine = new DeepThinkEngine();
const result = engine.analyzeArgument("あなたの引数...");

console.log(result.markdown);
```

## 📖 設計原則

| 原則 | 説明 |
|------|------|
| **段階的ロード** | サブスキルをオンデマンドでロード、認知オーバーロード回避 |
| **メタデータ駆動** | 各思考ノードには信頼度、ソースなどのメタデータを添付 |
| **メモリ永続化** | 思考プロセスは自動保存、クロスセッション回復対応 |
| **構造化出力** | JSON/Markdown/HTML マルチフォーマットサポート |
| **全程ユーザー介入** | チェックポイント設計でユーザーが方向をコントロール |
