## 🚀 Inicio Rápido

### Uso Básico

```
Usuario: ¿Cómo pensar profundamente?
Asistente: Por favor describe el tema o pregunta sobre la que quieres reflexionar profundamente...
```

### Modos de Ejecución

**1️⃣ Ejecución Progresiva (Recomendada)**
- Ejecutar por fases con puntos de control para tu intervención
- Ajusta la dirección del análisis en cualquier momento, añade más información
- 📖 [Guía Detallada](skill.md#ejecución-progresiva)

**2️⃣ Ejecución en Un Paso**
- Completa todo el análisis de una vez (Nivel 1-3 cadena completa)
- Adecuado para necesidades de pensamiento simples y rápidas

### Carga por Niveles

| Nivel | Objetivo | Marco | Tiempo |
|--------|----------|-------|--------|
| **Nivel 1** | Análisis Rápido | Marco 5W1H | ~30s |
| **Nivel 2** | Análisis Profundo | Pensamiento Crítico + Sistémico | ~2min |
| **Nivel 3** | Conocimiento Esencial | Validación Cruzada Multidimensional + Principios Primarios | ~10min |

## 🧩 Módulos de Sub-Habilidades

### Meta-Habilidad

#### 🔮 Reflexividad
> Identifica la influencia mutua entre el pensador y el sistema, evita el sesgo cognitivo

**Casos de Uso**: Auto-revisión pre-decisión, identificación de sesgos, clarificación de posición
**Prioridad**: Activada primero

---

### Sub-Habilidades Principales

#### 🔍 Pensamiento Crítico
> Evalúa la calidad del argumento, identifica falacias lógicas, examina supuestos

**Métodos**:
- Clarificación de Valores
- Separación Hecho/Opinión
- Principios Primarios + 5 Por Qué
- Detección de Falacias Lógicas

**Casos de Uso**: Analizar fiabilidad de puntos de vista, evaluar fuerza de argumentos

#### 🌐 Pensamiento Sistémico
> Comprende relaciones entre elementos, identifica bucles de retroalimentación, predice comportamiento del sistema

**Métodos**:
- Matriz de Atribución Multidimensional
- Análisis de Cascada de Segundo/Tercer Orden
- Estiramiento de Escala de Práctica

**Casos de Uso**: Análisis de problemas complejos, decisiones multifactoriales

#### 💡 Pensamiento Creativo
> Rompe patrones de pensamiento, genera洞察 únicas, conecta conocimiento interdisciplinario

**Método**: SCAMPER

**Casos de Uso**: Innovación de producto, resolución de problemas, diseño de soluciones

#### 📝 Expresión Estructurada
> Transforma resultados del pensamiento en salida clara

**Casos de Uso**: Escritura, discursos, presentaciones, documentación

### Análisis Multi-Perspectiva

#### 👥 Seis Perspectivas

| Perspectiva | Enfoque Central | Pregunta Clave |
|-------------|-----------------|----------------|
| 🧠 Psicología | Motivación/Cognición/Emoción | ¿Qué quiere realmente el usuario? |
| 📡 Comunicación | Información/Símbolo/Influencia | ¿Cómo se recibe y distorsiona la información? |
| 📦 Producto | Necesidades/Valor/Iteración | ¿Qué tiene sentido construir? |
| 💰 Economía | Incentivos/Demanda-Oferta/Costo | ¿Qué impulsa el comportamiento? |
| 🏛️ Política | Poder/Interés/Alianza | ¿Cómo juegan las partes? |
| 🎨 Diseño | Experiencia/Empatía/Esencia | ¿Qué conmueve al usuario? |

```json

  "load_config": {

    "max_level": 3,
    "auto_escalation": true

  "output_config": {
    "auto_generate": true,
    "markdown_template": "default",
    "html_template": "assets/thinking_output.html",
    "required_sections": {

      "critical_thinking": true,
      "systemic_thinking": true,
      "first_principles": true,
      "multi_perspective": true,
      "confidence_assessment": true

  }
}
```

## 🔧 Uso de Scripts

### Motor Python

```bash
# Análisis rápido
python script/deep_think.py --input "Tu pregunta"

# Análisis de pensamiento crítico
python script/deep_think.py --input "Tu argumento" --skill critical

# Analizar desde archivo
python script/deep_think.py --file argument.txt --output markdown
```

### Motor JavaScript

```javascript
const { DeepThinkEngine } = require('./script/think_engine.js');

const engine = new DeepThinkEngine();
const result = engine.analyzeArgument("Tu argumento...");

console.log(result.markdown);
```
