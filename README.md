> 🤔 分析问题时，总是浮于表面？

## 🚀 快速开始

### 基本用法

```
用户: 如何深度思考？
助手: 请描述你想要深入思考的问题或话题...
```

### 执行模式

**1️⃣ 渐进性执行（推荐）**
- 分阶段执行，在关键节点设置断点供你介入
- 可随时调整分析方向、补充信息
- 📖 [详细说明](skill.md#渐进性执行)

**2️⃣ 一步执行**
- 一次性完成所有分析（Level 1-3 全链路）
- 适合简单快速的思考需求

### 层级加载

| 层级 | 目标 | 框架 | 耗时 |
|------|------|------|------|
| **Level 1** | 快速分析 | 5W1H 框架 | ~30秒 |
| **Level 2** | 深入分析 | 批判性思维 + 系统性思维 | ~2分钟 |
| **Level 3** | 本质洞察 | 多维交叉验证 + 第一性原理 | ~10分钟 |

## 🧩 子技能模块

### 元技能

#### 🔮 反身性觉察 (Reflexivity)
> 识别思考者与系统的相互影响，避免认知偏见

**适用场景**: 决策前自检、偏见识别、立场澄清
**优先级**: 最先激活

---

### 核心子技能

#### 🔍 批判性思维 (Critical Thinking)
> 评估论证质量，识别逻辑谬误，检验假设前提

**方法列表**:
- 价值澄清
- 事实/观点剥离
- 第一性原则 + 5Why 追问
- 逻辑谬误识别

**适用场景**: 分析观点可靠性、评估论证强度

#### 🌐 系统性思维 (Systemic Thinking)
> 理解要素关系，识别反馈循环，预测系统行为

**方法列表**:
- 多维归因矩阵
- 二阶/三阶传导分析
- 实践尺度拉伸

**适用场景**: 复杂问题分析、多因素决策

#### 💡 创造性思维 (Creative Thinking)
> 突破思维定式，产生新颖洞见，连接跨域知识

**方法**: SCAMPER

**适用场景**: 产品创新、问题解决、方案设计

#### 📝 结构化表达 (Structured Expression)
> 将思考结果转化为清晰输出

**适用场景**: 写作、演讲、汇报、文档撰写

---

### 多视角分析

#### 👥 六大视角

| 视角 | 核心关注 | 关键问题 |
|------|----------|----------|
| 🧠 心理学 | 动机/认知/情感 | 用户真正想要什么？ |
| 📡 传播学 | 信息/符号/影响 | 信息如何被接收和扭曲？ |
| 📦 产品经理 | 需求/价值/迭代 | 做什么才有意义？ |
| 💰 经济学 | 激励/供需/成本 | 什么驱动行为？ |
| 🏛️ 政治学 | 权力/利益/联盟 | 各方如何博弈？ |
| 🎨 设计学 | 体验/共情/本质 | 什么让用户心动？ |

## ⚙️ 配置说明

编辑 `config/config.json` 自定义行为：

```json
{
  "load_config": {
    "default_level": 1,
    "max_level": 3,
    "auto_escalation": true
  },
  "output_config": {
    "auto_generate": true,
    "markdown_template": "default",
    "html_template": "assets/thinking_output.html",
    "required_sections": {
      "reflexivity": true,
      "critical_thinking": true,
      "systemic_thinking": true,
      "first_principles": true,
      "multi_perspective": true,
      "confidence_assessment": true
    }
  }
}
```

## 🔧 脚本使用

### Python 引擎

```bash
# 快速分析
python script/deep_think.py --input "你的问题"

# 批判性思维分析
python script/deep_think.py --input "你的论证" --skill critical

# 从文件分析
python script/deep_think.py --file argument.txt --output markdown
```

### JavaScript 引擎

```javascript
const { DeepThinkEngine } = require('./script/think_engine.js');

const engine = new DeepThinkEngine();
const result = engine.analyzeArgument("你的论证...");

console.log(result.markdown);
```

## 📖 设计原则

| 原则 | 说明 |
|------|------|
| **渐进式加载** | 按需加载子技能，避免认知过载 |
| **元数据驱动** | 每个思考节点携带置信度、来源等元数据 |
| **内存持久化** | 思考过程自动存储，支持跨会话恢复 |
| **结构化输出** | JSON/Markdown/HTML 多格式支持 |
| **用户全程介入** | 断点设计确保用户掌控分析方向 |
