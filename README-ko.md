## 💡 이런 고민을 해본 적 있으신가요?

> 🤔 문제를 분석해도 항상 표면적인 것만 다루게 됩니다
> 🔍 깊이 생각하고 싶지만 어디서부터 시작해야 할지 모르겠습니다
> 💭 복잡한 의사결정을 앞두고 있지만 체계적인 방법론이 없습니다
> 📝 사고 과정이 복잡해서 결과를 정리하기 어렵습니다

**Deep Thinking Workflow** 는 당신을 위해 만들어졌습니다 — 심층 사고를 실행 가능하고 재현 가능하게 만드는 점진적 사고 방법론입니다.

---

## ✨ 핵심 기능

| 기능 | 설명 |
|------|------|
| 🏗️ **3단계 점진 모드** | 빠른 분석 → 구조적 심화 → 본질적 통찰 |
| 🔧 **모듈식 서브스킬** | 비판적 사고, 체계적 사고, 창의적 사고... |
| 🎯 **다각도 분석** | 심리학,传播학, Product, 경제학... |
| 📊 **시각화 출력** | Markdown + HTML + ECharts 인터랙티브 차트 |
| 🛑 **점진적 실행** | 핵심 포인트에 체크포인트, 전방위 제어 |

## 🚀 빠른 시작

### 기본 사용법

```
사용자: 깊이 생각하는 방법은?
어시스턴트: 깊이 생각하고 싶은 문제나 주제를 설명해주세요...
```

### 실행 모드

**1️⃣ 점진적 실행 (권장)**
- 단계별로 실행하고 체크포인트에서 개입 가능
- 분석 방향 조정, 정보 추가 언제든지 가능
- 📖 [상세 가이드](skill.md#점진적-실행)

**2️⃣ 일괄 실행**
- 한 번에 모든 분석 완료 (Level 1-3 풀 체인)
- 간단하고 빠른 사고 필요할 때 적합

### 레벨별 처리

| 레벨 | 목표 | 프레임워크 | 시간 |
|------|------|------------|------|
| **Level 1** | 빠른 분석 | 5W1H 프레임워크 | ~30초 |
| **Level 2** | 심층 분석 | 비판적 사고 + 체계적 사고 | ~2분 |
| **Level 3** | 본질적 통찰 | 다면 교차 검증 + 제1원칙 | ~10분 |

## 🧩 서브스킬 모듈

### 메타 스킬

#### 🔮 반성 (Reflexivity)
> 사고자와 시스템의 상호 영향을 식별하고 인지 편향 회피

**적용 상황**: 의사결정 전 자가 검사, 편향 식별, 입장 명확화
**우선순위**: 가장 먼저 활성화

---

### 핵심 서브스킬

#### 🔍 비판적 사고 (Critical Thinking)
> 논증의 품질을 평가하고, 논리적 오류를 식별하고, 가정 전제를 검증

**메서드**:
- 가치 명확화
- 사실/의견 분리
- 제1원칙 + 5Why 추궁
- 논리적 오류 탐지

**적용 상황**: 견해 신뢰성 분석, 논증 강도 평가

#### 🌐 체계적 사고 (Systemic Thinking)
> 요소 관계를 이해하고, 피드백 루프를 식별하고, 시스템 행동을 예측

**메서드**:
- 다면 귀인 매트릭스
- 2차/3차 전도 분석
- 실천 규모 신축

**적용 상황**: 복잡한 문제 분석, 다요소 의사결정

#### 💡 창의적 사고 (Creative Thinking)
> 사고 패턴을 돌파하고, 새로운 통찰을 창출하고, 분야 간 지식을 연결

**메서드**: SCAMPER

**적용 상황**: 제품 혁신, 문제 해결, 솔루션 설계

#### 📝 구조화 표현 (Structured Expression)
> 사고 결과를 명확한 출력으로 변환

**적용 상황**: 글쓰기, 발표, 프레젠테이션, 문서 작성

---

### 다각도 분석

#### 👥 6가지 관점

| 관점 | 핵심 관심 | 핵심 질문 |
|------|----------|----------|
| 🧠 심리학 | 동기/인지/감정 | 사용자가 정말 원하는 것은 무엇인가? |
| 📡传播학 | 정보/기호/영향 | 정보가 어떻게 수신되고 왜곡되는가? |
| 📦 产品管理 | 니즈/가치/반복 | 무엇을 构建해야 의미 있는가? |
| 💰 경제학 | 인센티브/수요공급/비용 | 무엇이 행동을驱动하는가? |
| 🏛️ 정치학 | 권력/이익/동맹 | 각 측이 어떻게 게임하는가? |
| 🎨 디자인 | 경험/공감/본질 | 무엇이 사용자를感动させるか? |

## 📤 출력 예시

### Markdown 보고서 구조

```markdown
# {주제명} 심층 분석 보고서

## 1. 핵심 정보 정리
## 2. 반성
## 3. 비판적 사고 분석
## 4. 체계적 사고 분석
## 5. 본질적 통찰 (제1원칙)
## 6. 다각도 심층 분석
## 7. 심층 결론
## 8. 사고 경로 정리
## 9. 신뢰도 평가
## 10. 라이프사이클 예측
```

### HTML 시각화 컴포넌트

| 컴포넌트 | 타입 | 설명 |
|----------|------|------|
| 핵심 공식 표시 | 하이라이트 카드 | 바이럴 공식/통찰 시각화 |
| 다면 귀인 | 파이/도넛 차트 | ECharts 인터랙티브 |
| 전도 효과 | 누적 막대 그래프 | 다단계 효과 표시 |
| 인과 관계도 | 샌키 다이어그램 | 요소 관계 시각화 |
| 라이프사이클 예측 | 선 그래프 | 트렌드 예측 |
| 다각도 레이더 | 레이더 차트 | 심도 비교 |
| 신뢰도 미터 | 진행 바 | 각 레벨 신뢰도 |

## ⚙️ 설정

`config/config.json` 을 편집하여 동작을カスタマイズ:

```json
{
  "load_config": {
    "default_level": 1,
    "max_level": 3,
    "auto_escalation": true
  },
  "output_config": {
    "auto_generate": true,
    "markdown_template": "default",
    "html_template": "assets/thinking_output.html",
    "required_sections": {
      "reflexivity": true,
      "critical_thinking": true,
      "systemic_thinking": true,
      "first_principles": true,
      "multi_perspective": true,
      "confidence_assessment": true
    }
  }
}
```

## 🔧 스크립트 사용

### Python 엔진

```bash
# 빠른 분석
python script/deep_think.py --input "당신의 질문"

# 비판적 사고 분석
python script/deep_think.py --input "당신의 논증" --skill critical

# 파일에서 분석
python script/deep_think.py --file argument.txt --output markdown
```

### JavaScript 엔진

```javascript
const { DeepThinkEngine } = require('./script/think_engine.js');

const engine = new DeepThinkEngine();
const result = engine.analyzeArgument("당신의 논증...");

console.log(result.markdown);
```
