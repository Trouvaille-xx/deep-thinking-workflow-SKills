# 输出生成子技能 (Output Generation)

## 核心职责

1. 支持用户选择**执行模式**（渐进性/一步）
2. 在关键节点设置**断点**供用户介入
3. 询问用户是否需要**输出MD/HMTL**
4. 生成两类输出文档

## 执行模式

### 渐进性执行模式（推荐）

分阶段执行，在关键节点暂停询问用户：

```
🔴 断点1: 调研完成
    → 询问: 是否继续？是否补充信息？
    
🔴 断点2: 分析完成，输出前
    → 询问: 是否生成 Markdown 报告？
    → 询问: 是否生成 HTML 可视化报告？
    → 用户可在此处调整/补充内容
```

### 一步执行模式

分析完成后统一询问输出选项：

```
分析完成
    ↓
🔵 询问: 是否生成 Markdown 报告？ (Y/N)
🔵 询问: 是否生成 HTML 可视化报告？ (Y/N)
```

## 用户交互流程

### 渐进性执行

```
阶段1: 信息收集 → [断点1] → 阶段2: 深度分析 → [断点2] → 输出生成
                              ↓                              ↓
                        用户可介入                    选择输出格式
                        补充/调整内容                 MD / HTML
```

## 输出文件命名规范

```
{主题}_{YYYYMMDD}_{HHMMSS}_analysis_report.md
{主题}_{YYYYMMDD}_{HHMMSS}_analysis_report.html
```

示例：
```
SBTI_20260410_152100_analysis_report.md
SBTI_20260410_152100_analysis_report.html
```

## 输出流程

```
1. 收集分析结果
   ├── 核心洞察
   ├── 归因数据
   ├── 传导效应
   ├── 多视角评分
   └── 置信度评估

2. 生成Markdown（用户选择时）
   ├── 按照模板结构填充
   ├── 保持原始分析的完整性
   └── 保存到工作目录

3. 生成HTML（用户选择时）
   ├── 读取Markdown内容
   ├── 提取可视化数据
   ├── 渲染ECharts图表
   └── 保存到工作目录

4. 展示预览
   ├── HTML报告预览
   └── 提供下载链接
```

## 质量检查清单

输出前必须检查：

- [ ] Markdown文档结构完整，所有章节都已填充
- [ ] HTML图表容器ID唯一，无JavaScript冲突
- [ ] 所有图表都有数据，无空图表
- [ ] ECharts实例正确初始化
- [ ] 响应式设计在移动端可正常显示
- [ ] 文件保存路径正确

## 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 图表容器不存在 | 跳过该图表，继续渲染其他图表 |
| 数据格式错误 | 使用默认数据，标记置信度为低 |
| ECharts加载失败 | 显示占位符文字 |
| 文件写入失败 | 报错并提示用户 |
