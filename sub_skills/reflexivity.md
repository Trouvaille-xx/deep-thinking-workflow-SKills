# 反身性觉察 (Reflexivity Awareness)

## 核心概念

### 什么是反身性？

```
传统认知模型：                    反身性模型：

  观察者 → 客观现实 → 认知          观察者 ↔ 现实 → 认知
       (独立存在)                       (相互建构)

  "我在观察一个与我无关的系统"       "我参与了系统的构建"
```

**关键洞察**：思考者不是中立的旁观者，而是系统的参与者。观察行为本身会改变被观察的对象。

### 反身性三角

```
         认知框架
          ↙    ↘
    观察行为 ←→ 被观察系统
          ↘    ↙
           反馈
```

## 自我检查框架

### 立场清单

| 维度 | 自问 | 记录 |
|------|------|------|
| 专业立场 | 作为[职业]，我倾向于... | |
| 利益相关 | 我/我的组织从[结论]中获益吗？ | |
| 时间视角 | 此刻vs长期，结论会不同吗？ | |
| 情感卷入 | 我的情绪在多大程度上影响了判断？ | |
| 认知偏好 | 我偏好[保守/激进]的结论？ | |
| 归属影响 | 我的群体身份如何影响了我？ | |

### 偏见识别清单

| 偏见类型 | 描述 | 自检问题 |
|---------|------|---------|
| 确认偏误 | 选择性关注支持自己观点的信息 | "我有没有忽略反对证据？" |
| 后见之明 | 事后认为结果可预测 | "我真的事先预料到了吗？" |
| 过度自信 | 高估自己判断的准确性 | "最坏的情况会是什么？" |
| 群体极化 | 与他人讨论后观点更极端 | "如果只有我一个人会怎么想？" |
| 归因偏差 | 成功归自己，失败归环境 | "环境给了我什么优势？" |

### 反身性协议

```
Phase 1: 立场澄清
1. 我为什么问这个问题，而不是另一个？
2. 我的专业背景如何影响判断？
3. 我的利益立场是什么？

Phase 2: 过程审视
4. 我的思考过程合理吗？
5. 有什么认知偏差在起作用？
6. 如果换个立场，结论会变吗？

Phase 3: 结论检验
7. 什么会让我的结论失效？
8. 我愿意公开为自己的结论辩护吗？
9. 如果我错了，后果是什么？
```

## 应用场景

### 1. 决策前自检

在做重要决策前使用：

```
□ 我清楚自己的利益立场吗？
□ 我有没有确认偏误？
□ 我愿意接受与预期相反的信息吗？
□ 如果我的判断错了，最坏的结果是什么？
□ 三年后再看这个决定，我会怎么看？
```

### 2. 观点分析前

在分析他人观点前使用：

```
□ 说话者的立场是什么？
□ 什么经历塑造了他的观点？
□ 他有什么利益动机？
□ 他可能忽略了什么？
□ 我对他的观点有什么先入为主的判断？
```

### 3. 团队讨论中

在集体讨论时引入反身性：

```
"在我们继续之前，让我们各自说说自己为什么支持这个观点，以及我们可能忽略了什么。"
```

## 练习题

### 练习1: 产品决策反身性分析
你正在评估一个新功能，数据显示用户反馈积极，但你内心很想做这个功能。
- 你的专业立场如何影响了你对数据的解读？
- 你的情感偏好如何影响了判断？
- 如果不支持这个功能的人来看这些数据，会得出什么结论？

### 练习2: 竞争对手分析
你正在分析一个竞品，管理层普遍认为它不行。
- 你的组织立场如何影响了分析？
- 你有去看支持竞品的证据吗？
- 如果你是竞品的PM，你会怎么评价它？

---

*反身性觉察不是怀疑一切，而是一种有结构的自知之明。明智地使用它，而不是用它来否定自己的判断。*
