# 政治学视角 (Political Perspective)

## 核心概念

### 1. 权力的本质
```
权力 = 让他人做他们原本不会做的事的能力

权力来源:
- 法定权力 (Position)
- 资源权力 (Resource)
- 信息权力 (Information)
- 专家权力 (Expertise)
- 关系权力 (Network)
- 声望权力 (Reputation)
```

### 2. 利益相关方模型
```
                      高利益
                        ↑
                        │
        满足其利益    密切监控    随时告知
        ←───────────────┼───────────────→
       │                │                │
低     │    (C) 满意    │     (D) 信息    │ 高
影     │                │     告知       │ 影
响     │                │                │ 响
力     ─────────────────┼─────────────────→
       │                │                │
       │    (A) 重点    │     (B) 保持    │
       │    管理       │     利益        │
       │                │     满足       │
        ─────────────────┴─────────────────→
                        ↓
                        ↓
                    高利益
```

| 象限 | 策略 | 说明 |
|------|------|------|
| A (高影响/高利益) | 重点管理 | 密切合作、充分沟通 |
| B (低影响/高利益) | 保持满意 | 满足需求、不过度投入 |
| C (高影响/低利益) | 保持信息 | 定期通报、控制期望 |
| D (低影响/低利益) | 监控 | 必要时告知 |

## 核心分析维度

### 1. 权力分布分析

| 权力类型 | 来源 | 影响方式 | 识别信号 |
|---------|------|---------|---------|
| 正式权力 | 职位 | 命令、奖励、惩罚 | 组织架构 |
| 资源权力 | 资源控制 | 分配/扣押资源 | 预算审批 |
| 信息权力 | 信息掌控 | 选择性传递 | 关键信息节点 |
| 专家权力 | 专业能力 | 技术权威 | 解决关键问题 |
| 关系权力 | 人际网络 | 影响力传递 | 非正式圈子 |
| 声望权力 | 个人声誉 | 榜样作用 | 员工敬重 |

### 2. 利益分析框架

```
表面利益（说什么）→ 真正利益（要什么）→ 核心利益（最在意什么）

示例:
"要增加预算"      → "项目需要更多资源" → "个人业绩/影响力"
"反对这个方案"    → "我的建议没被采纳" → "尊重/认可"
"太激进了"        → "担心风险"          → "安全/稳定"
```

### 3. 联盟形成分析

**联盟形成条件**：
```
共同利益 + 沟通渠道 + 信任基础 + 领导协调 = 联盟

联盟类型:
- 利益联盟 (基于共同利益)
- 理念联盟 (基于共同信念)
- 情感联盟 (基于人际情感)
```

**联盟动态**：
```
联盟形成 → 共同行动 → 成果分配 → 联盟持续/瓦解
                              ↓
                        利益分配不均 → 联盟瓦解
```

### 4. 制度与规则

| 制度类型 | 特征 | 约束力 |
|---------|------|-------|
| 正式制度 | 明文规定 | 强（违规有惩罚） |
| 非正式规范 | 潜规则 | 中（违规有舆论压力） |
| 文化传统 | 习惯成自然 | 弱（内化） |

**制度分析问题**：
```
1. 正式规则是什么？实际执行如何？
2. 潜规则是什么？
3. 哪些规则可以被操纵/绕过？
4. 改变制度需要什么？
```

## 政治行为模式

### 1. 常见政治策略

| 策略 | 手段 | 风险 | 使用场景 |
|------|------|------|---------|
| 合纵连横 | 建立联盟 | 暴露意图 | 重大决策 |
| 借力打力 | 利用他人 | 可能失控 | 推动受阻 |
| 抛砖引玉 | 先提大要求 | 被拒绝 | 获取真实底线 |
| 移花接木 | 偷换概念 | 信任损失 | 危机时刻 |
| 以退为进 | 表面让步 | 被认为软弱 | 长期博弈 |
| 借尸还魂 | 利用他人成果 | 归属争议 | 资源争夺 |

### 2. 变革阻力分析

| 阻力来源 | 表现 | 应对策略 |
|---------|------|---------|
| 利益受损 | 公开反对/暗中抵制 | 补偿/分阶段 |
| 能力不足 | 担心无法胜任 | 培训/支持 |
| 认知差异 | 认为没必要 | 沟通/教育 |
| 情感依恋 | 怀念旧方式 | 尊重/过渡 |
| 组织惯性 | 习惯力量 | 试点/示范 |

### 3. 影响力技术

```
位置影响力 (Position):
- 争取关键岗位
- 参加重要会议
- 扩大可见度

专家影响力 (Expertise):
- 建立专业权威
- 发表专业观点
- 解决关键问题

关系影响力 (Relationship):
- 建立跨部门关系
- 维护关键人脉
- 互惠互助

信息影响力 (Information):
- 控制信息流
- 选择性分享
- 建立信息优势

激励影响力 (Incentive):
- 奖惩权
- 资源分配
- 认可系统
```

## 分析协议

### 快速政治分析 (2分钟)
```
1. 谁有决策权？(正式/非正式)
2. 各方利益是什么？
3. 谁会支持/反对？为什么？
4. 需要争取谁的支持？
```

### 深度政治建模 (5分钟)
```
1. 权力地图
   - 正式权力结构
   - 非正式影响力网络
   - 关键决策节点

2. 利益相关者分析
   - 各方利益诉求
   - 利益冲突点
   - 潜在联盟

3. 博弈分析
   - 各方筹码
   - 可选策略
   - 均衡结果预测

4. 变革阻力评估
   - 阻力来源
   - 阻力强度
   - 克服路径

5. 策略设计
   - 联盟构建
   - 信息策略
   - 激励设计
```

## 练习题

### 练习1: 新政策推行分析
- 各部门的利益是什么？
- 谁会是最强阻力？如何应对？
- 需要建立什么联盟？
- 如何设计政策使其更容易接受？

### 练习2: 跨部门项目推动
- 各部门投入产出比不同，如何平衡？
- 谁会搭便车？如何防止？
- 什么能真正调动各方积极性？
