# 心理学视角 (Psychology Perspective)

## 核心框架

```
行为 → 需要/动机 → 认知解释 → 情感反应 → 新的行为
  ↑                                              │
  └────────────── 反馈循环 ←─────────────────────┘
```

## 核心分析维度

### 1. 需要层次 (Maslow + Extensions)

| 层级 | 需求类型 | 驱动因子 | 产品映射 |
|------|---------|---------|---------|
| 生理 | 食物、睡眠、身体舒适 | 生存本能 | 功能性/可用性 |
| 安全 | 稳定、可预测、免于恐惧 | 保护本能 | 可靠性、安全保障 |
| 归属 | 爱、接纳、社群 | 社会本能 | 社交功能、社区 |
| 尊重 | 成就、认可、地位 | 心理本能 | 成就系统、徽章 |
| 认知 | 知识、好奇、理解 | 智识本能 | 探索功能、内容 |
| 审美 | 和谐、美感、秩序 | 感性本能 | 界面美学 |
| 自我实现 | 成长、潜能、意义 | 超验本能 | 个性化、使命 |

### 2. 动机类型

| 动机类型 | 特征 | 激发因子 | 典型场景 |
|---------|------|---------|---------|
| 趋利型 | 追求快乐、收益 | 奖励、认可 | 积分、游戏化 |
| 避害型 | 避免痛苦、损失 | 紧迫感、恐惧 | 限时、存量压力 |
| 成就型 | 挑战、掌控 | 难度适中的目标 | 任务、打卡 |
| 归属型 | 连接、认同 | 社群、身份认同 | 社区、勋章 |
| 自主型 | 选择、控制 | 自主权、灵活性 | 自定义、选项 |

### 3. 认知偏差清单

#### 判断与决策偏差
| 偏差名称 | 描述 | 识别信号 |
|---------|------|---------|
| 确认偏误 | 选择性关注支持自己观点的信息 | "你看，XX也这么说" |
| 锚定效应 | 对最初信息过度依赖 | 第一个价格影响判断 |
| 损失厌恶 | 损失比等量收益痛苦2倍 | 不愿取消订阅 |
| 现状偏差 | 偏好保持现有状态 | 默认选项 = 选择 |
| 过度自信 | 高估自己判断的准确性 | "我知道这是对的" |
| 峰终定律 | 对体验的记忆由高峰和结尾决定 | 结尾好=整体好 |

#### 社会认知偏差
| 偏差名称 | 描述 | 识别信号 |
|---------|------|---------|
| 群体极化 | 讨论后观点变得更极端 | "大家都觉得..." |
| 社会认同 | 模仿他人行为 | 随大流 |
| 权威偏差 | 过度依赖权威意见 | "专家说的" |
| 晕轮效应 | 以整体印象影响局部判断 | "大公司=质量好" |

#### 记忆偏差
| 偏差名称 | 描述 | 应用 |
|---------|------|------|
| 系列位置效应 | 开头和结尾比中间记得清 | 首因/近因效应 |
| 生动性偏差 | 鲜活例子 > 统计数据 | 故事 > 数字 |
| 事后偏见 | 事后认为结果可预测 | "我早就知道" |

## 分析协议

### 快速心理分析 (1分钟)
```
1. 目标用户是谁？他们的核心需求是什么？
2. 当前行为背后的动机是什么？（趋利/避害/成就/归属/自主）
3. 有什么认知偏差在影响判断？
4. 情感触发点在哪里？
```

### 深度心理建模 (5分钟)
```
1. 绘制用户动机地图
   - 表面行为 →
   - 隐性需求 →
   - 核心动机 →
   - 根本恐惧

2. 识别决策路径
   - 触发情境 →
   - 信息处理 →
   - 情感权衡 →
   - 最终行动

3. 分析情绪曲线
   - 体验高峰
   - 低谷点
   - 结尾感受

4. 预测行为改变阻力
   - 认知阻力
   - 情感阻力
   - 社会阻力
```

## 常用理论框架

### 1. 自我决定论 (SDT)
```
自主需求 + 胜任需求 + 归属需求 → 内在动机
```

**应用**：产品设计应满足三大心理需求而非只靠外部奖励

### 2. 认知失调理论
```
认知不一致 → 心理不适 → 行为调整/认知调整
```

**应用**：当用户行为与态度矛盾时，他们会调整其一

### 3. 心流理论 (Flow)
```
挑战水平 ─┬─ 太低 → 无聊
          ├─ 适中 → 心流（沉浸状态）
          └─ 太高 → 焦虑
```

**应用**：任务难度应匹配用户技能水平

### 4. 社会比较理论
```
向上比较 → 动力 or 挫败感
向下比较 → 满足 or 自满
```

**应用**：排行榜、成就系统要考虑社会比较效应

## 练习题

### 练习1: 为什么用户不取消订阅？
心理分析角度：
- 损失厌恶（不想失去已有权益）
- 现状偏差（懒得操作）
- 认知努力（取消流程太复杂）
- 沉默成本（已经用了很久）

### 练习2: 为什么限时折扣有效？
心理分析角度：
- 稀缺效应（不多见）
- 紧迫感（截止日期）
- 损失厌恶（错过=损失）
- 从众心理（别人也在买）
