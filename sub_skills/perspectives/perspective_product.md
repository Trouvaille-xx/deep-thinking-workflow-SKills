# 产品经理视角 (Product Manager Perspective)

## 核心思维框架

### 1. 产品经理三角

```
              价值
             /    \
            /      \
           /   三   \
          /   角 平   \
         /     衡     \
        └────────────┘
       用户 | 技术 | 商业

价值 = 对用户有用 × 技术可实现 × 商业可持续
```

### 2. 做与不做的决策框架

| 问题维度 | 做什么 | 不做什么 |
|---------|-------|---------|
| 用户价值 | 解决真痛点 | 痒点/伪需求 |
| 商业价值 | 有付费意愿 | 成本过高 |
| 技术可行 | 可实现 | 过于复杂 |
| 市场时机 | 窗口期 | 太早/太晚 |
| 竞争优势 | 差异化 | 同质化红海 |

### 3. 需求优先级框架

#### RICE 评分
```
RICE = (Reach × Impact × Confidence) / Effort

Reach:     触达用户数 (1-1000)
Impact:    对用户的影响 (0.25-3)
Confidence: 置信度 (50%-100%)
Effort:    人力月 (1-100)
```

#### MoSCoW 方法
```
Must have:   必须有（核心功能）
Should have:  应该有（重要但非关键）
Could have:   可以有（锦上添花）
Won't have:   这个版本不做
```

## 核心分析维度

### 1. 用户研究方法

| 方法 | 获取信息 | 适用阶段 | 成本 |
|------|---------|---------|------|
| 用户访谈 | 深度动机、痛点 | 发现问题 | 中 |
| 问卷调查 | 规模态度、量化 | 验证假设 | 低 |
| 可用性测试 | 行为路径、障碍 | 方案验证 | 中 |
| 数据分析 | 实际行为、漏斗 | 优化迭代 | 低 |
| A/B测试 | 因果关系 | 方案选择 | 高 |

### 2. 用户故事地图

```
用户画像: [典型用户描述]

用户目标 → [我要做X] → [以便达成Y]

分解:
[功能A] → [子任务A1] → [子任务A2]
              ↓
[功能B] → [子任务B1]
```

### 3. 价值度量框架

| 指标类型 | 指标名称 | 含义 | 目标 |
|---------|---------|------|------|
| 北极星指标 | 唯一关键指标 | 反映核心价值 | 提升 |
| 先行指标 | 预测未来 | 关注趋势 | 监测 |
| 滞后指标 | 结果呈现 | 复盘用 | 达标 |

**北极星指标特征**：
- 清晰、可衡量
- 反映用户价值
- 业务长期健康
- 全团队理解并认同

## 产品决策流程

### 1. 问题发现阶段
```
用户反馈/数据异常/市场洞察/竞品分析
              ↓
        问题定义
              ↓
        价值假设
              ↓
      验证优先级排序
```

### 2. 方案设计阶段
```
问题拆解 → 解决方案 → MVP设计 → 用户测试 → 迭代优化
```

### 3. 迭代发布阶段
```
灰度发布 → 数据监测 → 反馈收集 → 全量/回滚
```

## 产品分析协议

### 快速产品分析 (2分钟)
```
1. 目标用户是谁？核心痛点是什么？
2. 现有解决方案是什么？
3. 我们的差异化优势是什么？
4. 如何验证这个假设？
5. 成功指标是什么？
```

### 深度产品建模 (10分钟)
```
1. 市场分析
   - TAM/SAM/SOM 规模
   - 市场趋势（增长/稳定/萎缩）
   - 竞争格局（直接/间接/潜在）

2. 用户分析
   - 用户画像（人口统计/行为/动机）
   - 用户旅程地图
   - 痛点优先级

3. 产品分析
   - 核心功能
   - 价值主张
   - 商业模式

4. 增长分析
   - 获客渠道
   - 留存机制
   - 变现路径

5. 风险分析
   - 技术风险
   - 市场风险
   - 运营风险
```

## 常用框架

### 1. 波特竞争战略
```
成本领先     → 价格战
差异化       → 品牌/技术
集中化       → 细分市场
```

### 2. 创新扩散曲线
```
创新者 2.5% → 早期采用 13.5% → 早期大众 34% → 晚期大众 34% → 落后者 16%
      ↑                    ↑
   风险承受          社会认同驱动
```

### 3. 用户生命周期
```
Acquisition (获取) → Activation (激活) → Retention (留存)
                                         ↓
                               Revenue (变现) ← Referral (推荐)
```

## 练习题

### 练习1: 评估一个新功能
- 这个功能解决什么用户痛点？
- 用户真的需要还是我们觉得需要？
- 实现成本vs用户价值？
- 如何设计MVP验证？

### 练习2: 增长策略制定
- 核心增长杠杆是什么？
- 获客/激活/留存/变现哪个最弱？
- 有限的资源应该投在哪里？
- 如何设置仪表盘监控？
