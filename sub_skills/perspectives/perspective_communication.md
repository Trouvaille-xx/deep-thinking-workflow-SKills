# 传播学视角 (Communication Perspective)

## 核心模型

### 传播基本模型 (Shannon-Weaver)
```
信源 → 编码 → 信号 → 噪音 → 解码 → 信宿
       ↑                          ↓
       ←←←←←←← 反馈回路 ←←←←←←←←←
```

**关键洞察**：
- 信息在传播过程中会衰减和扭曲
- 噪音（物理/语义/社会）影响接收
- 反馈决定传播效果

## 核心分析维度

### 1. 信息编码分析

| 编码层次 | 内容 | 示例 |
|---------|------|------|
| 明示层 | 字面意义 | "限时特价" |
| 隐含层 | 文化/情境含义 | "紧迫感" |
| 情感层 | 情绪调动 | "错过等一年" |
| 行动层 | 指令/引导 | "立即购买" |

**编码检查**：
```
1. 我的信息在每个层次是否一致？
2. 目标受众能正确解码吗？
3. 哪些信息可能被误解？
4. 如何减少语义噪音？
```

### 2. 传播渠道分析

| 渠道类型 | 特征 | 适用场景 |
|---------|------|---------|
| 人际传播 | 深度、反馈强、传播慢 | 高信任度信息 |
| 群体传播 | 互动性强、形成社群 | 社区运营 |
| 大众传播 | 覆盖面广、单向、延迟反馈 | 品牌曝光 |
| 数字传播 | 即时、多路径、可追踪 | 互动营销 |

**渠道匹配矩阵**：

| 信息类型 | 最佳渠道 | 理由 |
|---------|---------|------|
| 紧急通知 | Push + 短信 | 即时触达 |
| 深度内容 | 公众号/博客 | 可沉淀、深度阅读 |
| 社交扩散 | 微博/短视频 | 便于转发、病毒传播 |
| 信任建立 | 1v1/社群 | 双向互动、个性化 |

### 3. 舆论形成机制

```
触发事件
    ↓
信息生产 → 内容包装 → 意见领袖背书
    ↓                           ↓
核心受众接收 → 二次传播 → 破圈扩散
    ↓
舆论形成 → 极化/反转 → 议题冷却
```

**舆论生命周期**：

| 阶段 | 时间 | 特征 | 干预窗口 |
|------|------|------|---------|
| 潜伏期 | 0-6h | 少量讨论，议题未明 | 黄金干预期 |
| 爆发期 | 6-48h | 快速扩散，情绪强烈 | 关键窗口 |
| 极化期 | 48-72h | 立场对立，理性下降 | 困难期 |
| 消退期 | 72h+ | 新话题出现，关注转移 | 长尾影响 |

### 4. 符号学分析

```
能指 (Signifier) → 符号形式（声音/图像/文字）
    ↓
所指 (Signified) → 符号含义（概念/情感/价值）
    ↓
意指 (Signification) → 能指与所指的关系

符号解读 = 文化语境 × 个人经验
```

**常见符号应用**：

| 符号类型 | 正面联想 | 负面联想 |
|---------|---------|---------|
| 自然元素 | 纯净、原始、环保 | 落后、不发达 |
| 科技元素 | 先进、高效、未来 | 冷冰、疏离 |
| 人物符号 | 信任、成功、专业 | 争议、风险 |

## 传播效果模型

### 1. AIDA 模型
```
Attention (注意) → Interest (兴趣) → Desire (欲望) → Action (行动)
    ↑                    ↑                ↑            ↑
  吸引眼球            持续关注         情感调动      促使决策
```

### 2. 传播阶梯模型
```
无知 → 知晓 → 了解 → 喜欢 → 偏好 → 信任 → 购买
```

**应用**：不同阶段需要不同的传播策略

### 3. 双面传播效应
```
单面传播：快速建立态度，但面对反对观点易动摇
双面传播：说服较慢，但态度更稳固持久
```

## 分析协议

### 快速传播分析 (1分钟)
```
1. 核心信息是什么？（一句话）
2. 通过什么渠道传播？
3. 目标受众是谁？
4. 预期传播路径？
```

### 深度传播建模 (5分钟)
```
1. 信息解构
   - 明示层：说什么？
   - 隐含层：暗示什么？
   - 情感层：调动什么情绪？
   - 行动层：期望什么行动？

2. 传播路径设计
   - KOL/关键节点是谁？
   - 传播的触发点/分享动机？
   - 噪音干扰点在哪里？
   - 如何设计二次传播？

3. 舆论监控点
   - 什么时候可能出现反转？
   - 预警信号是什么？
   - 应对预案？
```
