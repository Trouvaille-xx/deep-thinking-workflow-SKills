# 经济学视角 (Economics Perspective)

## 核心原理

### 1. 理性人假设与现实
```
古典经济学: 人是完全理性的最优决策者
行为经济学: 人受认知偏差影响，存在系统性偏差

现实策略:
- 利用理性假设预测大规模行为趋势
- 利用行为经济学理解个体偏差
```

### 2. 激励相容原理
```
代理人利益 ≠ 委托人利益 → 道德风险
         ↓
设计激励机制让代理人利益与委托人一致
```

## 核心分析维度

### 1. 成本分析框架

| 成本类型 | 特征 | 决策相关性 |
|---------|------|----------|
| 固定成本 | 不随产量变化 | 规模效应判断 |
| 变动成本 | 随产量线性变化 | 边际决策 |
| 机会成本 | 次优选择的收益 | 资源稀缺决策 |
| 沉没成本 | 已发生、不可回收 | 沉没成本谬误 |
| 边际成本 | 多生产一单位的成本 | 产量决策 |
| 交易成本 | 达成交易的成本 | 市场选择 |

**沉没成本谬误警示**：
```
错误做法: "已经投入这么多，不能放弃"
正确做法: "只看未来的成本和收益"
```

### 2. 供给需求分析

```
均衡价格 ← 供给曲线 ↘
                   ↘ (P*)
                   ↗
          需求曲线 ↗

影响供给因素:
- 生产成本
- 技术进步
- 竞争对手
- 政策环境

影响需求因素:
- 收入水平
- 替代品价格
- 消费者偏好
- 预期
```

**供需分析问题**：
```
1. 什么因素会导致需求曲线移动？
2. 什么因素会导致供给曲线移动？
3. 新的均衡点在哪里？
4. 价格和数量如何变化？
```

### 3. 竞争结构分析

| 市场结构 | 特征 | 代表 | 竞争策略 |
|---------|------|------|---------|
| 完全竞争 | 同质产品、无进入壁垒 | 农产品 | 成本领先 |
| 垄断竞争 | 差异化、众多小厂商 | 餐饮 | 差异化 |
| 寡头垄断 | 少数厂商、相互依赖 | 手机 | 博弈策略 |
| 完全垄断 | 单一厂商、无替代品 | 公用事业 | 政府管制 |

### 4. 博弈论基础

**经典博弈场景**：

| 博弈类型 | 特征 | 典型案例 |
|---------|------|---------|
| 囚徒困境 | 个体理性→集体非理性 | 价格战 |
| 智猪博弈 | 大小玩家不对称 | 搭便车 |
| 斗鸡博弈 | 针锋相对、不退让 | 市场竞争 |
| 猎鹿博弈 | 合作收益>单干 | 合作研发 |

**博弈分析框架**：
```
1. 游戏规则是什么？
2. 各方的收益函数是什么？
3. 各方的占优策略是什么？
4. 纳什均衡在哪里？
5. 如何改变博弈结构？
```

## 经济思维工具

### 1. 边际分析
```
决策依据: 边际收益 > 边际成本 → 采取行动

应用场景:
- 定价决策
- 产量决策
- 投资决策
- 时间分配
```

### 2. 机会成本思维
```
每项选择都有机会成本

决策问句:
"这项资源最好的替代用途是什么？"
"不做这件事，我能做什么？"
```

### 3. 比较优势
```
绝对优势: A在X上比B强
比较优势: A在X上比在Y上相对更强

应用: 专注发挥比较优势，交换其他
```

### 4. 规模经济与范围经济

| 类型 | 概念 | 条件 |
|------|------|------|
| 规模经济 | 规模↑ → 单位成本↓ | 固定成本高、边际成本低 |
| 范围经济 | 多产品共享 → 成本↓ | 共享资源/渠道/技术 |

### 5. 信息不对称

| 类型 | 描述 | 解决方案 |
|------|------|---------|
| 逆向选择 | 签约前信息不对称 | 信号发送/筛选 |
| 道德风险 | 签约后行为不可观测 | 激励契约/监督 |
| 委托代理问题 | 利益不一致 | 股权激励/绩效考核 |

## 分析协议

### 快速经济分析 (2分钟)
```
1. 各方的成本和收益是什么？
2. 激励结构是怎样的？
3. 边际决策是什么？
4. 替代选择是什么？
5. 信息是否对称？
```

### 深度经济建模 (5分钟)
```
1. 市场分析
   - 市场结构是什么？
   - 供需弹性如何？
   - 均衡价格和数量？

2. 成本分析
   - 成本结构？
   - 规模经济存在吗？
   - 机会成本是什么？

3. 竞争分析
   - 竞争格局？
   - 博弈策略？
   - 进入壁垒？

4. 激励分析
   - 各方利益诉求？
   - 代理问题存在吗？
   - 如何设计激励相容？

5. 风险分析
   - 主要不确定性？
   - 尾部风险？
   - 对冲手段？
```
