# 创造性思维 (Creative Thinking)

## 核心框架

```
         思维定式 (Mindsets)
              ↓
    ┌─────────┼─────────┐
    ↓         ↓         ↓
  发散 ──→  转化  ──→  收敛
    ↓         ↓         ↓
  数量     质量      精选
```

## 突破定式技术

### 1. 重新定义问题 (Reframing)

| 原问题 | 重定义后 | 启示 |
|--------|---------|------|
| "如何减少迟到？" | "如何让准时变得自然？" | 从惩罚→环境设计 |
| "如何卖更多咖啡？" | "如何让用户更享受早晨？" | 从产品→体验 |
| "如何省钱？" | "如何让每一分钱都值得？" | 从削减→价值最大化 |

### 2. 逆向思考 (Reversal)

```
正常思维: 如何让用户买更多？
逆向思维: 如何让用户不买？

正常思维: 如何改进产品？
逆向思维: 如何让产品变差？

→ 识别当前做法的反面
→ 极端情况会暴露什么？
→ 反过来成立的条件是什么？
```

### 3. 随机输入 (Random Input)

```
从词典随机取一个词 → 强制连接

问题：如何提升会议效率？
随机词：海龟
→  海龟般慢节奏思考（延长讨论时间？）
→  海龟的长寿（长期跟进机制？）
→  海龟缩进壳里（独处思考时间？）
```

### 4. 类比借用 (Analogy Migration)

```
自然系统 → 人工系统
生物灵感 → 商业方案

蜂巢 → 分布式协作网络
蚁群 → 路径优化算法
免疫系统 → 安全防御架构
```

## 创意生成技术

### SCAMPER
| 字母 | 技术 | 问题 |
|------|------|------|
| S | Substitute | 替代什么？ |
| C | Combine | 组合什么？ |
| A | Adapt | 怎么适应？ |
| M | Modify | 修改什么？ |
| P | Put to other use | 还有什么用途？ |
| E | Eliminate | 删除什么？ |
| R | Reverse | 反过来呢？ |

### 概念扩展 (Concept Extension)
```
已知概念A ──→ 抽象化 ──→ 提取本质 ──→ 应用于B

手机 → 便携 → 随时随地 → 随时随地的学习 → 随时随地的医生
                        → 随时随地的健身指导
```

## 分析协议

### 快速创意激发 (2分钟)
```
1. 重新定义问题（3种方式）
2. 逆向思考（2个反问）
3. 随机连接（1个随机词强制连接）
4. 快速评估（可行性 ★★★）
```

### 深度创意工作流 (10分钟)
```
Phase 1: 发散 (5分钟)
- SCAMPER 至少每项2个想法
- 随机输入 × 5
- 类比借用 × 3

Phase 2: 转化 (3分钟)
- 合并相似想法
- 评估创新性 (1-10)
- 评估可行性 (1-10)

Phase 3: 收敛 (2分钟)
- 选出 Top 3
- 快速原型描述
- 确定下一步
```

## 练习题

### 练习1: 老年人社交
**问题**: 如何让老年人不感到孤独？
- 重定义：孤独 ←→ 连接质量 vs 数量
- 逆向：如果老年人不需要社交？
- 随机词：桥梁 → 跨代际连接

### 练习2: 减少食物浪费
**问题**: 如何减少餐厅食物浪费？
- SCAMPER: Eliminate（取消自助区？）
- 逆向：如何制造更多浪费？
- 自然类比：生态系统零浪费
